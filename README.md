# Age Calculator

## About
A simple Age Calculator built using HTML, CSS and JavaScript.

## Features
- Enter date of birth
- Calculate age in years
- Empty date validation
- Future date validation
- Reset button

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Use
1. Open the project.
2. Select your date of birth.
3. Click Calculate Age.
4. View your age.
5. Click Reset to clear the input.
